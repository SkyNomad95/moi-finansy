Политика конфиденциальности приложения «Мои финансы»

Эта политика описывает работу приложения «Мои финансы» для iPhone, версия 1.0.

Финансовые записи

Приложение сохраняет введённые операции, долги, заметки и регулярные платежи на устройстве. Для работы не нужна учётная запись. Приложение не отправляет эти записи разработчику, не показывает рекламу и не использует встроенную аналитику.

Резервное копирование

По вашему запросу приложение экспортирует резервную копию в файл JSON. В системном окне «Файлы» вы выбираете место хранения. Если вы сохраняете файл в iCloud Drive, его хранением управляет Apple. Разработчик не получает доступ к файлу. Приложение не добавляет к файлу отдельное шифрование. Удалить экспортированную копию можно через «Файлы».

Face ID и уведомления

Блокировку приложения можно включить в настройках. iOS выполняет проверку Face ID или код-пароля и возвращает приложению результат. Приложение не получает биометрические данные или код-пароль. Если вы разрешили уведомления, напоминания о платежах планируются на устройстве.

Курсы валют

Для пересчёта валют приложение загружает опубликованные курсы с сайта Национального банка Кыргызской Республики по HTTPS. Запрос не содержит ваших финансовых записей. Как при обычном веб-запросе, принимающая сторона может видеть IP-адрес и технические параметры соединения.

Удаление данных и связь с разработчиком

Записи можно удалять в приложении. При удалении приложения iOS удаляет его локальные данные. Созданные вами копии остаются в выбранном месте до тех пор, пока вы их не удалите. Если вы пишете в поддержку, ваш адрес и содержание письма используются для ответа на обращение.

По вопросам конфиденциальности обращайтесь через страницу поддержки «Мои финансы».
